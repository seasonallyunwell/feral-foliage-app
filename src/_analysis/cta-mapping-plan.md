## Implementation Notes

- Some articles receive multiple CTAs where content covers multiple aspects
- Priority should go to topic-specific CTAs (e.g., humidity articles → humidifier CTAs)
- Bundle CTAs (humidity-bundle, starter kits) work well for beginner-focused content
- Tool articles should receive tool-specific CTAs (pruning → shears, repotting → pots/soil)
- General articles can receive broader CTAs or be deprioritized if content is informational only
